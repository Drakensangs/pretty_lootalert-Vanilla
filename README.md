# 🎉 **pretty_lootalert** (Vanilla 1.12.1)

> [!IMPORTANT]
> **pretty_lootalert** requires [**ClassicAPI**](https://github.com/brues-code/ClassicAPI) in order to function.

[**s0h2x**](https://github.com/s0h2x)'s [**pretty_lootalert**](https://github.com/s0h2x/pretty_lootalert) ported to 1.12.1 with the following features:

 - toggleable toasts for looting items, crafting, winning rolls, looting money, learning recipes & gaining honor
 - toggleable animations & sound effects
 - shift + click an item toast to link the item in the chat
 - support for artifacts (might be useful if your server has artifacts)
 - global & toast specific item filters
 - advanced overrides for every toast type

## 👨‍💻 **Authors**

Original addon: s0h2x

Vanilla 1.12.1 version: Drakensangs
